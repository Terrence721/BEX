# Security Policy

## Supported versions

This is a design/architecture project on a single `main` branch, not a versioned release — only the current state of `main` is in scope.

## Reporting a vulnerability

Please **do not** open a public issue for a security concern.

Use GitHub's private reporting instead: go to the [Security tab](https://github.com/Terrence721/BEX/security) and select **Report a vulnerability**. This opens a private advisory visible only to the maintainer until it's resolved.

You can expect an initial response within a few days.
