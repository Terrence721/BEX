Supporting data — a SQL row, not code

StrategyAssignment ClientId · InstrumentClass · StrategyId · Version · EffectiveFrom · Mode (Shadow / Canary / Live)

Promoting a new strategy version is a StrategyAssignment row update, not a deploy — the same binary already runs all three modes. Shadow logs decisions without acting on them; Canary acts, but only for the client/instrument slice named in the row; Live is the default for everyone else.

See the design doc for the reasoning. Part of BEX.
